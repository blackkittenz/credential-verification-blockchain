
# Credential Verification Blockchain

## Deskripsi
Project ini mengembangkan sistem verifikasi kredensial akademik berbasis blockchain menggunakan smart contract Solidity.

## Tujuan
- Menyimpan catatan kredensial pada blockchain.
- Memverifikasi keaslian kredensial.
- Mencegah perubahan data kredensial tanpa otorisasi.
- Mendukung proses verifikasi yang transparan.

## Teknologi
- Solidity
- Remix IDE
- Ethereum Virtual Machine (EVM)

## Struktur Project
- `contracts/` — kode smart contract Solidity.
- `docs/` — dokumentasi project.
- `test/` — dokumentasi dan skenario pengujian.

## Status
Tahap awal pengembangan.

## Keamanan
Tidak menyimpan private key, seed phrase, atau data pribadi mahasiswa yang sebenarnya.
